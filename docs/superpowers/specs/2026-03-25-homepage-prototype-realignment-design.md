# 首页原型纠偏设计
**日期：** 2026-03-25

## 背景

当前公开站首页已经完成功能闭环，但视觉方向与 Stitch 原型首页偏差明显。现有版本采用浅底编辑式官网语言，而目标原型是深色科技品牌首页：固定深色顶栏、整屏 Hero、球体主视觉、案例双卡展示、产品四列推荐轮播和底部品牌拼贴区。

本次纠偏只处理首页及其直接依赖的公开站壳层：

- 首页 `#/home`
- 首页顶栏样式
- 首页页脚样式
- 首页 Hero 搜索条样式

不改动后台模块，不改动公开站其余页面的路由和业务逻辑。

## 目标

在不破坏现有功能的前提下，把首页重构为接近 Stitch 原型的深色科技首页，同时保留：

- 后台站点配置驱动品牌名称与首页眉标题
- 后台轮播驱动首页主视觉标题、跳转与自动轮播
- 首页搜索条到搜索页的跳转逻辑
- 产品、案例详情跳转
- 页面进入动效与桌面/移动端可用性
- 顶栏右侧搜索框交互钩子

## 结构设计

### 1. 顶栏

- 保留现有 `TopNav` 组件和搜索 test hooks
- 在首页启用深色变体
- 中间导航改为更紧凑的科技官网布局
- 右侧保留搜索展开交互、登录入口和控制台入口

### 2. Hero

- 整屏深色背景，使用 Stitch 原型的发光球体主视觉作为背景层
- 左侧展示：
  - 品牌眉标题
  - `GLINT RISE / 光速上升`
  - 首页说明文案
  - 深色搜索条
  - 当前轮播标题与跳转 CTA
- 保留 `home-hero-banner-title`、`home-hero-banner-target`、`home-hero-banner-dot-*` 测试钩子

### 3. 案例区

- 使用双卡结构代替之前的左列表右大图
- 主卡展示重点案例，副卡展示第二案例
- 继续链接到现有案例详情页
- 文案使用可读中文，案例标题可保留英文专名

### 4. 产品区

- 改为四列深色产品卡
- 保留已有产品切换状态，让箭头可以轮播热门产品集合
- 产品卡继续跳转到已完成的产品详情页

### 5. 品牌叙事区

- 采用原型中的拼贴结构：
  - 大横图文案卡
  - 品牌能力卡
  - 稳定性数据卡
  - 合作 CTA 卡

### 6. 页脚

- 改为深色极简样式
- 保留品牌、页脚链接和版权信息

## 文案策略

- 布局、比例、层级对齐原型
- 非专有术语以中文为主
- 品牌名、产品名、案例专名允许保留英文
- 避免再次出现编码异常文本

## 测试策略

- 首页组件测试先失败后通过，锁定：
  - 深色原型布局标记
  - Hero 轮播钩子保留
  - 案例区、产品区、品牌区存在
- 导航组件测试锁定首页深色导航变体与搜索钩子并存
- 实现后执行：
  - `npm run test:unit -- src/pages/HomePage.test.jsx src/components/layout/TopNav.test.jsx`
  - `npm run build`
  - 如有需要再跑 `npm run verify:routes -- http://127.0.0.1:4184`
