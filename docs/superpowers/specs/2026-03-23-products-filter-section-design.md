# Products Filter Section Design

**Date:** 2026-03-23

## Goal
在不破坏当前 `#/products` 页面上半段策展结构的前提下，为页面下半段补一个产品筛选结果区，使该页面开始承担 PRD 中“产品列表页（含搜索/标签筛选）”的职责。

## Approved Direction
- 保留当前页面上半段“旗舰产品 + 右侧策展入口”结构
- 在页面下半段新增筛选结果区
- 筛选结果区包含：搜索框、分类筛选、标签筛选、结果数量、产品卡片网格
- 筛选操作在当前页内完成，不创建新路由
- 结果卡片继续复用现有产品卡片，点击进入 `#/product/:id`
- `#/products/hot` 保留为热门产品独立页

## Scope
本次只处理公开站 `#/products` 页面，不处理后台产品管理页面，不新增独立筛选结果路由，不重构现有上半段结构。

## Data And Behavior
- 复用现有产品数据 `products`
- 复用当前产品搜索分类与标签定义
- 页面内本地状态驱动筛选结果
- 搜索支持关键词匹配产品名称、短名、标签、描述和元信息
- 分类和标签支持组合过滤
- 空结果时显示明确空状态和返回热门页/重置入口

## Verification
- `npm run build`
- `npm run verify:routes -- http://127.0.0.1:4173`
- 路由验收新增 `#/products` 筛选结果区的检查：
  - 能找到筛选区控件
  - 输入关键词后结果发生变化
  - 点击标签后结果被收窄
  - 结果卡片可点击
