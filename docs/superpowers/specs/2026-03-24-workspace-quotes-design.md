# Workspace Quotes Design

## 目标

为 `#/workspace/quotes` 提供一个可完整跑通的五步询报价流程，覆盖需求导入、产品匹配、供应商推荐、报价参数设置、标准报价单生成，并与现有导出中心联动。

## 设计边界

### 页面边界

- 单路由：`#/workspace/quotes`
- 页面内部使用 5 步流程，不再拆成 5 个孤立页面
- 页面顶部展示最近询价单，可继续编辑已有草稿或开始新询价

### 步骤设计

1. Step1 需求导入/新建
   - 支持粘贴模板文本模拟 Excel 导入
   - 支持在线添加需求行
   - 校验必填字段：需求名称、关键词、数量、目标交期
2. Step2 产品匹配结果
   - 根据关键词、标签、分类、摘要匹配产品
   - 每条需求生成主匹配项和候选项
   - 支持手动替换、追加、删除匹配产品
3. Step3 供应商推荐与排序
   - 依据产品关联供应商、评级、适配度、交期、价格带生成推荐
   - 默认按综合评分排序
   - 支持按价格、工期、工艺能力重排
   - 支持为每个产品确认主供应商
4. Step4 加价/工期余量
   - 按产品填写加价幅度、模具费、工期余量
   - 实时生成对外报价预览
   - 员工默认不直接显示内部成本，只显示计算后的对外报价
   - 总监可看到内部成本基线
5. Step5 标准报价单/导出
   - 生成标准报价单 mock 文件并下载
   - 保存询价单状态为 `quoted`
   - 支持跳转导出中心，并将产品/供应商/标题预填到导出中心

## 数据模型

### 询价单主记录

- `id`
- `title`
- `status`: `draft` / `quoted` / `archived`
- `currentStep`
- `ownerId` / `owner`
- `requirements[]`
- `matches[]`
- `supplierSelections[]`
- `pricing[]`
- `quoteSheet`
- `logs[]`
- `createdAt` / `updatedAt`

### 派生规则

- 产品匹配、供应商推荐、报价预览都以当前持久化产品/供应商数据为输入
- 供应商显示必须复用供应商模块脱敏规则
- 标准报价单生成后保存快照，重复下载返回同一份快照

## 权限规则

- 员工、总监可访问 `#/workspace/quotes`
- 开发维护不可访问
- 员工可完成询价流程，但带报价导出仍受导出中心现有权限限制
- 总监可查看更完整的价格基线信息

## 测试策略

- 单元测试覆盖：
  - 导入解析与校验
  - 产品匹配与供应商推荐算法
  - 报价计算与标准报价单生成
  - mock service 的创建、更新、生成与权限行为
- 路由/浏览器回归覆盖：
  - 询价页权限
  - 五步流程完整跑通
  - 标准报价单下载
  - 导出中心预填联动
  - 供应商模块回归不受影响
