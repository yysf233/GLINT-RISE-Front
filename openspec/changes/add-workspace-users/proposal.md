# Proposal: add-workspace-users

## Why
- PRD 中“权限与用户管理页”仍是待开发状态
- 现有登录和角色判断仍依赖静态账号，无法体现后台改角色、停用账号、审批权限后的真实链路
- 后续“日志与监控”模块需要复用用户与审批上下文

## What Changes
- 新增后台 `#/workspace/settings/users` 模块
- 新增用户列表、详情、新建/编辑和权限申请审批
- 将 mock 认证切换到用户管理存储作为数据源
- 补充路由权限、导航配置、浏览器回归和 OpenSpec

## Impact
- 员工与总监可访问权限与用户模块
- 开发维护角色仍不可进入业务后台的权限管理模块
- 登录、会话恢复和角色权限会读取最新用户配置
