# Proposal: add-workspace-logs

## Why
- PRD 中“日志与监控”仍是最后一个明确未落地的后台正式模块。
- 当前后台已具备产品、项目、轮播、供应商、导出、询报价、站点配置和用户权限等 mock CRUD，缺少统一日志汇总视图会影响项目验收闭环。
- 全面回归测试要求覆盖角色权限、前后台联动和异常可见性，需要一个可验证的日志与告警页面承接。

## What Changes
- 新增后台 `#/workspace/settings/logs` 页面。
- 新增日志种子数据、mock service、API 封装和本地持久化存储键。
- 接入后台导航、路由鉴权和浏览器回归脚本。
- 回填 PRD 与 OpenSpec，明确员工受限视图、总监全量视图和告警确认业务。

## Impact
- 员工和总监可在后台查看日志与监控。
- 开发维护角色继续被限制在内容维护域，不能访问业务日志。
- 浏览器回归新增日志模块验收点，项目回归范围更完整。
