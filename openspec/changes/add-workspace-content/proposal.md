# Proposal: add-workspace-content

## Why
- `#/workspace/content` 之前只是开发维护角色的说明页，占位意味明显，尚未形成真实工作流。
- PRD 中开发维护需要承担站点内容维护、首页轮播调整和公开展示标签治理职责。
- 现有公开站已经完全由 mock CRUD 驱动，需要把开发维护侧入口补成可操作模块，才能闭合前后台联动验收。

## What Changes
- 将 `#/workspace/content` 从占位说明页升级为真实内容管理台。
- 新增开发维护侧内容服务，聚合公开站文案、轮播和产品公共标签数据。
- 支持开发维护直接调整文案、轮播顺位/上下线、产品展示标签，并同步到前台。
- 补充单元测试、浏览器回归、PRD 和 OpenSpec。

## Impact
- 开发维护拥有清晰可执行的内容治理工作台。
- 前台首页、产品详情与搜索页会直接反映内容台的改动。
- 采购、报价、供应商等敏感业务模块权限边界保持不变。
